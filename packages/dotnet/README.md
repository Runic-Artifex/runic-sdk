# Runic Toolkit packages

This directory contains the NuGet packages behind Runic Toolkit. Most applications should begin with [RunicToolkit.Templates](https://www.nuget.org/packages/RunicToolkit.Templates) rather than assembling the low-level hosting packages themselves.

For package selection, installation, and working applications, see the [repository guide](https://github.com/Runic-Artifex/runic-toolkit#readme), [documentation](https://github.com/Runic-Artifex/runic-toolkit/tree/main/docs), and [examples](https://github.com/Runic-Artifex/runic-toolkit-examples). Preview packages target .NET 10 and are MIT licensed.
