# `@runic-artifex/vue`

Vue composable for clients generated by Runic Views. The generated modules
import `@runic-artifex/views`, so install both:

```sh
npm install @runic-artifex/vue@preview @runic-artifex/views@preview
pnpm add @runic-artifex/vue@preview @runic-artifex/views@preview
bun add @runic-artifex/vue@preview @runic-artifex/views@preview
```

Previews are published under the `preview` dist-tag. Install the versions that
match your Runic SDK packages. Vue 3.5 or later is supported.

```vue
<script setup lang="ts">
import { useView } from "@runic-artifex/vue";
import type { CounterPageReference } from "./generated/counter.js";

const props = defineProps<{ page: CounterPageReference }>();
const { state, client, error } = useView(() => props.page);
</script>

<template>
  <button :disabled="!client" @click="client?.increment()">{{ state?.count ?? "…" }}</button>
  <p v-if="error" role="alert">{{ error }}</p>
</template>
```

`useView(source)` returns shallow refs `{ state, client, error }` and `retry()`:

- A generated page reference, or `{ connect: connect<Name> }` for a root
  ViewModel, is connected while the current effect scope (normally the
  component) is active. Disposing the scope or changing the reference disposes
  the client. A reference is identified by its `connect` function, so a getter
  that returns a new `{ connect: connectWorkspace }` object does not reconnect.
- An already connected client is observed and left to its owner.
- The source can be a value, a ref or a getter such as `() => props.page`.
- `error` holds a failed connection; `retry()` connects again.
