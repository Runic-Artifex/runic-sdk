# ADR 0004: Publication license is pending

- Status: Superseded by [ADR 0014](./0014-mit-license.md)
- Date: 2026-07-22

## Context

The repository is intended to contain reusable infrastructure, but API ownership, direct and transitive dependency licensing, bundled frontend assets, and publication terms have not completed review.

## Current rule

No source or package license is granted by this repository until this ADR is replaced by an accepted license decision. Public visibility must not be interpreted as permission to reuse or redistribute the code.

Public package publication is blocked until dependency inventory, notices, SBOM linkage, ownership, and license review are approved.

This restriction described the repository state from 2026-07-22 until the MIT
decision was accepted on 2026-08-04. It is retained as historical context and
is no longer the current licensing rule.
