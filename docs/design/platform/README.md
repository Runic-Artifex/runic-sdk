# Platform service designs

The designs of Runic.Platform's native services: the investigation behind each
contract, what each operating system provides, the delivery matrix and, where
it applies, the security review. They describe the .NET packages; they are not
cross-language contracts, which live under [specs](../../../specs/README.md). Each
package guide links to its design.

- [Privileged operations](privileged-operations.md)
- [Secret storage](secret-storage.md)
- [Opening files and URLs](open-activation.md)
- [Trash](trash.md)
- [File transfers](file-transfers.md)
- [Volumes](volumes.md)
- [Desktop applications](desktop-applications.md)
- [Thumbnails](thumbnails.md)

A section "Not planned" lists what a design leaves out, with no version
promise.
