# Dependency Notices Wave B contracts

Status: G2 implementation contract and handoff record. The key words **MUST**, **MUST NOT**, **SHOULD**, and **MAY** are normative.

Wave B adds deterministic restored-inventory adapters, explicit evidence acquisition, SBOM reconciliation, render/CLI/runtime surfaces, package-consumer verification, and Native-AOT verification. It does not replace or mutate the Wave A contracts.

## Compatibility boundary

- Every Wave A version 1 file in `spec/dependency-notices/` remains frozen. A Wave B reader MUST continue to accept valid v1 manual configuration, policy, evidence lock, notice document, and diagnostic documents.
- `dependency-notices.document.schema.v2.json` is an additive complete-document model. Version 2 carries the complete inventory, policy-decision, asset-text, SBOM-link, and modification model needed by the renderers and runtime. It does not silently migrate or reinterpret a v1 input.
- A producer MUST write the schema version it actually implements. A reader MUST reject unsupported major versions with `WUTNOTICE6003`. Migration, if later supplied, is a separate explicit operation.
- Canonical Package URLs, SPDX syntax and AST semantics, evidence SHA-256 identities, Wave A ordering, and existing diagnostic meanings remain unchanged.
- All public namespaces retain the `WebUIToolkit.DependencyNotices` parent. Ecosystem and delivery packages MAY use child namespaces such as `.NuGet`, `.Npm`, `.Sbom`, `.Acquisition`, `.Rendering`, `.Tool`, and `.Runtime`.
- No package may be published while the repository license/publication hold is active. Local packing and package-consumer testing do not constitute approval to publish.

## Cross-cutting invariants

1. `scan`, `policy`, `generate`, `verify`, `sbom`, rendering, runtime loading, build integration, and tests MUST NOT create a socket, perform DNS resolution, start a package-manager restore, or invoke a registry client.
2. Only an explicit `acquire` operation with an explicit network flag may use a transport. Redirects are independently revalidated.
3. Inventory is computed from already restored, locked inputs. An exact target/workspace is mandatory; adapters MUST NOT guess among candidates.
4. Evidence is hashed over original bytes before decoding. Renderers preserve evidence text; they do not classify, translate, truncate, or reinterpret it.
5. All generated bytes are independent of absolute roots, machine caches, clocks, cultures, environment variables, enumeration order, and platform newline defaults.
6. A cache hit is observationally identical to an empty-cache run. Cache deletion cannot change the result when all declared evidence is present.
7. Host paths, credentials, authorization data, registry tokens, and sensitive URL queries MUST NOT appear in output or diagnostics.

## Publication hold

The repository-wide license decision remains unresolved. Consequently package IDs in this contract are reserved implementation identities only. They may be packed into a local feed for G2 testing, but publishing, signing, or advertising a stable public package is prohibited until the publication hold is replaced by an approved ADR and the checklist in `public-api-approval.md` is complete.
