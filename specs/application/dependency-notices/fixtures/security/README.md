# Dependency Notices hostile security fixtures

These synthetic fixtures contain no third-party content. They define fail-closed expectations for bounded JSON, malformed Unicode, archive/path handling, HTML and URL injection, credential redaction, cache collisions, concurrent writers, and offline transport isolation.

Large payloads and concurrency races are generated by the executable security test project so the repository remains small. `invalid-utf8.hex` is a hexadecimal byte sequence rather than a text file, preventing editor normalization.
