# Application specifications

The previous preview Application Bridge protocol and its generated Bridge IR
have been retired. The current Runic Application Views contract is selected by
explicit .NET Window and View types and generated by the Views build tooling;
it is not a separately versioned wire protocol under `specs/application`.

See the [Views package documentation](../../packages/dotnet/Runic.Application.Views/README.md)
and maintained [examples](../../examples/README.md). The independent MessageFormat 2
specification remains under [`specs/translations`](../translations/README.md).
