# Runic SDK 0.7.0-preview.2

## Tools

- `dotnet-runic`, the project creator and the asset packer use Runic Command Line
  0.6.0-preview.2. SIGTERM and SIGQUIT now cancel a running command like Ctrl+C;
  a second signal exits at once with 128 plus the signal number. See the
  [Command Line upgrade notes](https://github.com/Runic-Artifex/runic-cli-sdk/blob/main/eng/release/notes/0.6.0-preview.2.md).
