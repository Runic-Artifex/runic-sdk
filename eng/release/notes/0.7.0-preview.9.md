# Runic SDK 0.7.0-preview.9

Install matching `0.7.0-preview.9` packages from NuGet and npm. Command Line
versions remain independent of this SDK.

## Content and navigation

- Retiring owned navigation content with nested Views no longer deadlocks when
  the browser unmounts its Views at the same time
  ([#245](https://github.com/Runic-Artifex/runic-sdk/issues/245)). A
  `WindowContentSession.Forget` outside model turns, as a navigator's
  retirement calls it, held a View attachment's lock while its bridges waited
  for a model turn, and the browser's unmount waited in a model turn for that
  lock. The application froze with an empty page area. Applications that call
  `Forget` inside a model turn to avoid the freeze can return to calling it off
  turn, as `INavigationPresentation.Forget` is documented.
