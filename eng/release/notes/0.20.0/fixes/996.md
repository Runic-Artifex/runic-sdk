- `dotnet runic dev` run elevated (as administrator) no longer lists WebView2's
  DevTools Protocol endpoint under `debugEndpoints` in its session file.
  WebView2 Runtime 150 and later ignores `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS`
  in an elevated process, so the endpoint never opened. The session file now
  lists it under `unavailableDebugEndpoints` with `"reason": "elevated"`, and
  `dev` prints a `[dev] Debugging:` hint to run it without elevation (#996).
