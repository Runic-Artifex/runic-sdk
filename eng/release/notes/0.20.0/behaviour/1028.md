- **WebKit's remote inspector opens only in Development on Linux** (#1028,
  D066.38). WebKitGTK opened it whenever `WEBKIT_INSPECTOR_SERVER` or
  `WEBKIT_INSPECTOR_HTTP_SERVER` was set, also with developer tools off, so a
  release could be scripted through it. Now, unless `DOTNET_ENVIRONMENT` (or
  else `ASPNETCORE_ENVIRONMENT`) is `Development`, the GTK 3 and GTK 4 hosts
  remove both variables from the process's environment before their first web
  view, also when `DevTools` is `true`. Processes the application starts after
  that no longer inherit them either. To inspect a build remotely, run it with
  `DOTNET_ENVIRONMENT=Development`.
