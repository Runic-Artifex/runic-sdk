## The Angular template can build with Vite (#946)

`dotnet new runic-app --frontend angular --angular-build vite` creates the
Angular frontend built, served and tested by Vite through the Analog Angular
plugin (`@analogjs/vite-plugin-angular` 2.9.7) instead of the Angular CLI.
`--angular-build cli` stays the default, and `dnx Runic.Create` asks for the
choice only for Angular. The components are the same; the Vite frontend adds
what the other frontends have:

- `runic()` from `@runic-artifex/vite-plugin-runic`, so the Runic development
  client and, with `@vitejs/devtools`, the Runic DevTools dock work as for
  React, Vue and Svelte; `dotnet runic dev` serves the page with Vite.
- With `--translations`, the Translations Vite plugin: an edited, added or
  removed message reaches the page under `dotnet runic dev` without a build.
- The component build target of trusted component mode, which the Angular CLI
  cannot build.

`vite build` checks no types, so the `build` and `typecheck` scripts run
`ngc --noEmit`. The frontend test runs on Vitest with the same plugin. Edited
component templates update in place (`liveReload`); other edits reload the
page. The template's tests build, type-check and test the new frontend with
every package manager, and open its production page in Chromium.
