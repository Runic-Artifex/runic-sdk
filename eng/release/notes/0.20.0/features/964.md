## A debugging guide (#964)

The new
[debugging guide](https://github.com/Runic-Artifex/runic-sdk/blob/v0.20.0/docs/debugging.md)
shows how to debug a Runic application end to end under `dotnet runic dev`:
the Window under the .NET debugger of Visual Studio, Rider or VS Code (the
template's launch profiles and `.vscode/` setup, `dev --no-window`, the IDE
contract and its session file), the browser's developer tools of each engine
(WebView2 and its DevTools Protocol endpoint, which an elevated Window does not
open; WKWebView with Safari's Web Inspector; WebKitGTK's inspector; an installed
browser) and how `dev` turns them on, the Runic dock, Runic Inspect, the
Performance panel and traces, and the Bridge analyzers. It names the two kinds
of "DevTools" apart (the browser's developer tools and the Vite DevTools dock),
says what reaches production (nothing), and ends with troubleshooting.
