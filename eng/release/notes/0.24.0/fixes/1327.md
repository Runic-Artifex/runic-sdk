- **A radio group can be bound to one field with `bindField`, React's `useField` and Svelte's `attach`.** These
  bindings treated a radio like a text input: they set every radio's `value` to the field's text, so the radios lost
  their options, and wrote the `value` of a radio that had not been checked (#1327). A radio now keeps its `value`, is
  checked while that is the field's text, and writes only when it becomes checked; with `commit: "change"` the choice
  is written at once, as for a checkbox or `<select>`. `bindField` takes the radios of a group together
  (`bindField(document.querySelectorAll("input[name=size]"), editor, EditorFields.size)`), Svelte's `{@attach
  size.attach}` goes on each radio, and React's new `radioProps(option)` is spread on each radio
  (`<input {...size.radioProps("Large")} />`). Angular's `[runicField]` and Vue's `v-model` already handled radios.
