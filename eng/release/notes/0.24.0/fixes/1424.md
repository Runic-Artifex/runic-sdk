- **A solution with a Runic application and its library builds each project once.** The Views targets' bootstrap pass
  passed `PublishAot=false` and the other publish properties it clears on to the projects it references, so MSBuild built
  a referenced library a second time with them, into the same `bin/` and `obj/`. The test project of
  `dotnet new runic-app --library --tests` also built the application a second time, with
  `RunicApplicationFrontendBuildEnabled=false`. With `-m`, these builds ran at the same time and could fail a solution
  build with an `IOException` on a file in `bin/` or `obj/runic-bridge/bootstrap/` (#1424). The bootstrap pass now builds
  its references with the properties of the real build, and the template's test project references the application without
  extra properties. Remove `AdditionalProperties="RunicApplicationFrontendBuildEnabled=false"` from a test project that is
  in one solution with the application it references.
