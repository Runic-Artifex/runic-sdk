- **A Runic Desktop window on Kestrel answers a WebSocket upgrade with another version with 426 and
  `Sec-WebSocket-Version: 13`.** An upgrade on a window's `_webui_ws_connect` path whose `Sec-WebSocket-Version` was not
  13 got 426 (Upgrade Required) without naming the version the host understands or the protocol it requires. As
  RFC 6455 §4.2.2 and §4.4 and RFC 9110 §15.5.22 ask, `Runic.Desktop.Kestrel` now adds `Sec-WebSocket-Version: 13`,
  `Upgrade: websocket` and `Connection: upgrade` to that 426, and every other 426 on the path carries
  `Upgrade: websocket` (#1418). Browsers send version 13, so pages are not affected.
