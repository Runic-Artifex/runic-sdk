- **On Linux, a write inside a watched directory no longer restarts its watch.** `RunicPathWatcher` identifies a
  watched directory by device, inode and birth time, so it notices a directory deleted and created again. On Linux,
  .NET's `Directory.GetCreationTimeUtc` returns the change time, so every entry created, renamed or deleted in the
  directory looked like a replacement: the watcher restarted its watch and read its targets again without an event
  (#1360). The watcher now reads the birth time with `statx`. On a file system that records no birth time, it keeps
  the change time and the restarts.
