- **The Views version diagnostic follows the producer's Runic release, and Views accepts the names of the 0.25
  rename.** `@runic-artifex/views` now reports its `version` diagnostic when a `hello` reply's `release` differs from
  its own release, whatever the producer is called; without `release` it compares the version of
  `Runic.Application.Views` or, from now on, `RunicArtifex.Application.Views`. The message names the producer instead
  of a .NET host. A `hello` reply whose `release` is not a string is an invalid response. For the rename window, from
  0.24 through 1.0.x, the .NET producer also reserves routes that start with `rax.`, and Runic Desktop and CS-WebUI
  serve the in-page menu bar as `rax.menu-bar` as well as `runic.menu-bar`, pushing under the name the page watched.
  0.24 still sends today's names. See the [rename window](../../../specs/application/README.md#rename-window).
