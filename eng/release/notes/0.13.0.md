# Runic SDK 0.13.0

## Specifications

- Every Runic Desktop conformance scenario now creates each resource it uses
  and names the surface in every request and session operation, so another
  implementation can run the scenarios without inventing a host, a surface or a
  default surface. `specs/desktop/conformance/operations.json` defines the
  closed operation vocabulary, and `npm run verify:contract` rejects a scenario
  that uses an id its `arrange` block or an earlier step did not create
  ([#667](https://github.com/Runic-Artifex/runic-sdk/issues/667)).
