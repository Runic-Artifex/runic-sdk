# Runic SDK 0.7.0-preview.7

Install matching `0.7.0-preview.7` packages from NuGet and npm. Command Line
versions remain independent of this SDK.

## WPF navigation and hosting fixes

- `RunicModelContext.Closed` is now marked experimental (`RUNICNAV001`), like
  the `IRunicModelContextLifetime` interface it implements. The member remains
  binary compatible; code that reads it directly must suppress `RUNICNAV001`.
- `WpfBridgeView` publishes its close before releasing the session, so a
  `CloseAsync` or `DisposeAsync` re-entered on the same thread during release
  joins that close instead of releasing the session twice.
- `NavigationSelector` no longer throws `ObjectDisposedException` when a
  selector detaches or selects after a selection ended during dispatcher
  shutdown.
- The hybrid WPF editor example keeps a save that the store completed even when
  Cancel arrives afterward, and no longer reports a cancelled web-editor open
  as a host failure after a fast unload and reload.
