# Runic SDK 1.0.0-rc.1

Install matching `1.0.0-rc.1` packages from NuGet and npm.
Command Line versions remain independent of this SDK.

## Fixes

- Svelte `useView`: `client`, `error` and `pending` notify their readers only
  when their own value changes; only `state` follows each published state
  (#791). Before, an `$effect` that read only `client` ran again with every
  state, so an effect that called a command whose answer changed the state
  called it again without end. `useCommand`, `useOperation`,
  `useLatestOperation`, `useField` and `useTextField` likewise notify a reader
  of one member only when that member changes. React `useView`, Vue `useView`
  and Angular `injectView` already behaved this way; tests now cover them.
