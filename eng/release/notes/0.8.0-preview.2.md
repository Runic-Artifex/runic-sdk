# Runic SDK 0.8.0-preview.2

Install matching `0.8.0-preview.2` packages from NuGet and npm. Command Line
versions remain independent of this SDK.

## Termination signals in windowless applications

- Ctrl+C, SIGTERM and SIGHUP no longer leave a windowless application running
  ([#279](https://github.com/Runic-Artifex/runic-sdk/issues/279)). The Desktop
  event loop absorbs the first signal only while a window is open or opening,
  or when the application sets the new
  `DesktopHostOptions.HandlesShutdownWithoutWindow`. Otherwise the signal keeps
  its default action and ends the process, as without
  `DesktopHostOptions.HandleShutdownSignals`. Before, a windowless application,
  for example one behind a status icon stopped by `systemctl --user stop` or a
  logout, ran until SIGKILL.
- To shut a windowless application down in order, set
  `HandlesShutdownWithoutWindow = true` and end its loop when
  `DesktopHost.ShutdownRequested` is cancelled. The status-icon example does
  this: a termination signal closes the counter, hides the icon, releases the
  single instance and exits 0.
