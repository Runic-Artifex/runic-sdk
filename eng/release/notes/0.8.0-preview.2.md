# Runic SDK 0.8.0-preview.2

Install matching `0.8.0-preview.2` packages from NuGet and npm. Command Line
versions remain independent of this SDK.

## Termination signals in windowless applications

- Ctrl+C, SIGTERM and SIGHUP no longer leave a windowless application running
  ([#279](https://github.com/Runic-Artifex/runic-sdk/issues/279)). The Desktop
  event loop absorbs the first signal only when something will end the
  application: an open window, or application code that read
  `DesktopHost.ShutdownRequested`. Otherwise the signal keeps its default action
  and ends the process, as without `DesktopHostOptions.HandleShutdownSignals`.
  Before, such an application, for example one behind a status icon stopped by
  `systemctl --user stop` or a logout, ran until SIGKILL.
- The status-icon example ends its loop on `host.Desktop.ShutdownRequested`, so
  a termination signal closes the counter, hides the icon, releases the single
  instance and exits 0. Do the same in a windowless application to shut down in
  order.
