## JavaScript debugging of the WebKitGTK Window is no longer a preview (#1171)

`dotnet runic dev`'s DevTools Protocol endpoint for the Window's WebKitGTK pages on Linux (since 0.21) is out of
preview: its CI job, VS Code's JavaScript debugger through the endpoint on GTK 3 and GTK 4, ran through 0.22 as D066.39
required. The docs, the `runic-app` template's README and launch configurations, and `dev`'s `[dev] Debugging:` line
drop the label. The docs now say what is tested by hand (Visual Studio on Windows with Runic DevKit, since 0.22) and
what Runic does not test (the C# Dev Kit `dotnet` configuration, Rider, Visual Studio's own Attach to Process dialog).
