## JavaScript debugging of the WebKitGTK Window is no longer a preview (#1171)

`dotnet runic dev`'s DevTools Protocol endpoint for the Window's WebKitGTK pages on Linux (since 0.21) is out of
preview: its CI job, VS Code's JavaScript debugger through the endpoint on GTK 3 and GTK 4, ran through 0.22 as D066.39
required. The docs, the `runic-app` template's README and launch configurations, and `dev`'s `[dev] Debugging:` line
drop the label.

The docs now say what was checked by hand: the template's `Window + WebKitGTK (Linux)` in VS Code (a C# breakpoint, then
a `Frontend/src` breakpoint through the endpoint), C# Dev Kit's `"type": "dotnet"` configuration on the launch profile,
Visual Studio's F5 on the launch profile with `dotnet runic dev --no-window`, and Runic DevKit's Debug the Window and
Attach to the Page (since 0.22). Runic does not test Rider or the steps of Visual Studio's own Attach to Process dialog.
The dotnet-runic README shows the C# Dev Kit configuration.
