## A menu command that opens the developer tools (#1188)

`DesktopMenuItem.OpenDevToolsCommandId` (`runic.devtools.open`) is the one command id with the reserved `runic.` prefix
that a menu bar item may name. Runic Desktop runs it itself for the key window, before the window's and the
application's command targets: it opens WebView2's DevTools window on Windows and, new, WebKit's Web Inspector on Linux
(GTK 3 and GTK 4), where `DesktopWindow.OpenDevToolsAsync` now opens it too. The item is enabled only in Development, in
a window whose developer tools are on; it is disabled on macOS (WKWebView opens its Web Inspector only from Safari), in
an installed browser, on CS-WebUI and in a custom window host, and context menus and status icon menus refuse it.

```csharp
MenuBar = developing
    ? [new DesktopMenu("View", [new DesktopMenuItem("Developer Tools", DesktopMenuItem.OpenDevToolsCommandId)])]
    : [],
```

The `runic-app` template declares it as View ▸ Developer Tools in Development, on Windows and Linux. See the
[Runic.Desktop README](../../../packages/dotnet/Runic.Desktop/README.md#the-webview2-devtools-window-and-devtools-extensions).
