## CS-WebUI: window placement (#1149, preview)

A `UseWebView` window of `Runic.Application.Views.CsWebUi` on Windows (WebView2) and Linux (WebKitGTK) now reports its
placement, the restored bounds and whether it is maximized, in `IRunicWindowPresentation.Placement`, also after the user
closed it, and takes one with `SetPlacementAsync`, `MaximizeAsync` and `RestoreAsync`. The new
`RunicCsWebUiHostOptions.Placement` restores a saved placement as each Window opens, as `RunicDesktopHostOptions.Placement`
does on Runic Desktop, and keeps it on a monitor that exists now. WebUI raises no event when a window moves, so the host
reads the placement every 500 ms while the window is shown and once more when it closes.

Wayland gives the size and maximized state without a position. A browser window, a macOS WebView and a `ShowWindow`
window report no placement and take only an initial size and a position within WebUI's limits. See
[Window placement](../../../packages/dotnet/Runic.Application.Views.CsWebUi/README.md#window-placement).
