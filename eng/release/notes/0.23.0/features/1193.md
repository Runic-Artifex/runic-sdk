## Leave Bridge blobs out of an application that does not use them (#1193)

An application whose ViewModels use no `RunicBlob` or `RunicUpload` sets the new MSBuild property `RunicViewsBlobs` to
`false`, as `RunicDesktopRegionHost` does for hosted regions (#1109):

```xml
<RunicViewsBlobs>false</RunicViewsBlobs>
```

The Bridge then offers no `blobs/1`, grants no uploads and serves nothing, and the CS-WebUI host starts no loopback
blob server for each window. A trimmed or NativeAOT publish leaves that code out: on linux-x64 the CS-WebUI size
fixture without ViewModels shrinks from 7,469,856 to 7,125,632 bytes (336 KB) and the Runic Desktop fixture from
10,612,040 to 10,541,736 bytes (69 KB). The property applies to every build, so `dotnet run` behaves as the publish. A
`RunicBlob` that still crosses the Bridge then has an empty URL, with warning 1205, as from a host that serves no
blobs. The default, `true`, is unchanged. See [MSBuild](../../../docs/msbuild.md#runicapplicationviews).
