- **An application that sets no `ApplicationIcon` gets one (#1207).** When `icons/icon.png` (or the file
  `RunicPackageIcon` names) exists, the build now derives the executable's Windows icon from it, Runic Desktop windows
  without `IconFile` show it on Windows and on macOS outside a bundle, and the macOS development bundle has it as
  `icon.icns`. An application with an `ApplicationIcon` keeps its own `.ico` for the executable, and its windows now
  show that icon instead of the generic one. If the icon is not a square PNG of at least 256 px, the build reports
  warning `RUNICICON001`, `RUNICICON002` or `RUNICICON003` and goes on without the derived icon; a project that treats
  warnings as errors then fails. Replace the icon, or set
  `<RunicApplicationIconGenerationEnabled>false</RunicApplicationIconGenerationEnabled>` to derive nothing.
  An application created from an earlier template can delete `icons/icon.ico` and its `ApplicationIcon` line, as the
  0.23 template does.
