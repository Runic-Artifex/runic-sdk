- On Windows, `dotnet runic dev` no longer leaves the Vite development server and `runic-translations serve` running
  after it stops. They outlived the package manager (bun or npm) that `dev` started, and `dev` ended only that
  package manager's tree, which no longer reached them once it had exited. An IDE that read `dev`'s output then
  waited for pipes those processes still held, and they kept the server's port. `dev` now runs the frontend's
  development server or watcher in a kill-on-close Job object and ends the job at the stop, and Windows ends it when
  `dev` itself is killed (#1163).
