- On WebView2, NVDA says a `DesktopWindow.AnnounceAsync` message also after a screen reader or another UI Automation
  client presses a button in the page. WebView2 activates the window to carry out the press and can leave the keyboard
  focus on the window itself while the button stays NVDA's focus; the window then announced the message with a UI
  Automation notification, which NVDA speaks only from the application of its focus, WebView2's browser process, so it
  said nothing. The page now announces the message in its live region in that case too, as it does while it has the
  focus (#1181).
