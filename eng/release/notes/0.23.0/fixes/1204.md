- On WebView2, keys typed after a screen reader or another UI Automation client presses a button in the page reach the
  page again. WebView2 activates the window to carry out the press and could leave the keyboard focus on the window
  itself, which has no control of its own, while the button stayed the screen reader's focus, so the keys went to the
  window. Whenever the window itself receives the focus, as after that press or when the user switches back to it, it
  now hands the focus to the page, or to the side panel when that had it last; the page focuses the element it had
  before (#1204).
