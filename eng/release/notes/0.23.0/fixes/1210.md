- `dotnet runic dev`'s debugging endpoint for the WebKitGTK Window (Linux) no longer detaches VS Code's JavaScript
  debugger when the Window takes long to exit before `dotnet watch` restarts it. The endpoint waited 1.5 seconds after the
  page went away and, when the old Window's inspector was still open then, took the page as closed in a running Window
  and ended the session, just before the restarted Window came. It now waits while that Window process runs: the
  session continues on the restarted Window's page, ends when another page takes the old one's place in a Window that
  keeps running, and ends when no restart comes within 3 minutes or `dev` stops (#1210).
