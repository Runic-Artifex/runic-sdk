## Windows administration (W1)

### Breaking changes

- `AdministrationErrorCategory.NotInstalled` (7) is reported for a component that
  is not installed or registered: class not registered (`0x80040154`, for example
  the Group Policy Management Console) and a missing WMI namespace or class
  (`0x8004100E`, `0x80041010`, for example the MicrosoftDNS provider on a computer
  without the DNS role). These were `Unavailable`, which now means only that an
  installed machine, endpoint or service cannot be reached (sdk#744).
- Native 1332 (no account mapping), 1376, 2220 (missing local group), 1387
  (missing member account) and 2221 are `NotFound`; 1388 (invalid member kind) is
  `InvalidData`. They were `NativeFailure` (sdk#738).
- Native 1460 (`ERROR_TIMEOUT`, for example a DNS server that does not answer) is
  `Unavailable`; it was `NativeFailure` (sdk#728).
- Native 1051 (`ERROR_DEPENDENT_SERVICES_RUNNING`), 1061 (a service cannot accept
  the control now) and 1062 (a service is not running) are `Conflict`, as 1056
  (already running) was; they were `NativeFailure` (sdk#739).

### Added

- `DomainMembership.DnsDomainName` and `ForestName`, read locally from
  `DsRoleGetPrimaryDomainInformation` without contacting a controller; null for a
  workgroup (sdk#744).
- `WindowsDomainClient.DiscoverControllerAsync(domainName, requirePrimary,
  requireWritable, DomainControllerNameFormat, cancellationToken)`:
  `DomainControllerNameFormat.Flat` returns the controller's and domain's NetBIOS
  names (`DS_RETURN_FLAT_NAME`), as `Win32_NTDomain.DomainControllerName` did
  (sdk#744).
- `WindowsFirewallClient.DeleteAllAsync(name)` deletes every rule of a native name,
  as `netsh advfirewall firewall delete rule name=…` does, and returns the number
  deleted; `DeleteAsync` still requires a unique identity (sdk#740).
- `FirewallClientOptions.WriteWhenLocalPolicyOverridden` and the
  `WindowsFirewallClient(FirewallClientOptions)` constructor: an explicit opt-in to
  write the local store while Group Policy overrides local rules or inbound traffic
  is blocked, which is refused by default. `GetLocalPolicyStateAsync()` reports the
  state as `FirewallLocalPolicyState` (sdk#740).
- `WindowsLocalGroupClient` (namespace `Accounts`): `AddMemberAsync`,
  `RemoveMemberAsync`, `EnumerateMembersAsync` and `GetGroupNameAsync` for local
  groups on the local or a remote computer (NetAPI). Groups and members are an
  `AccountReference.Name` or an `AccountReference.Sid`, so a well-known SID such
  as `S-1-5-32-544` addresses Administrators in every UI language. "Already a
  member" (1378) and "not a member" (1377) are returned as `false`; members carry
  SID, `DOMAIN\name` and `AccountKind` (sdk#738).
- `WindowsDnsResolverClient` (namespace `Dns`): resolver queries against one
  chosen DNS server by IP address (`DnsQueryEx` with a server list), bypassing the
  resolver cache, hosts file, LLMNR, NetBIOS and DNS suffixes. `QueryAsync(name,
  DnsRecordType)` and `ReverseLookupAsync(address)` return a `DnsResolution` with
  the `DnsResponseCode` (a name error is a result) and the answer records as
  `DnsAnswer` with typed `DnsRecordData` for A, AAAA, CNAME, PTR, MX, TXT, SRV and
  NS; `ReverseLookupName(address)` builds reverse names (sdk#728).
- `ProcessSnapshot.ImagePath`, the full executable path
  (`QueryFullProcessImageNameW`; null when access is denied), and
  `WindowsProcessClient.FindByImagePath(path)` to find the running instances of
  one program among programs that share a file name (sdk#729).
- `WindowsProcessClient.CloseOrKillAsync(processId, timeout)`: posts `WM_CLOSE` to
  the process's visible, unowned top-level windows (not console windows), waits, and terminates it otherwise, returning
  `ProcessCloseOutcome` (`NotRunning`, `Closed`, `Killed`);
  `TerminateAsync(processId, exitCode)` terminates at once (`taskkill /F`); and
  `StartAndWaitAsync(ProcessStartSpecification)` starts a program, optionally
  elevated through the shell's `runas` verb, and returns its exit code (sdk#729,
  sdk#739).
- `WindowsServiceClient.StopWithDependentsAsync(name, timeout)` stops the active
  dependents in dependency order, waits for them, requests the service's stop and
  returns the dependents it stopped (sdk#739).
- `ServiceSnapshot.ExecutablePath`: the executable of `BinaryCommandLine` as the
  Service Control Manager parses it, including the search through the prefixes of
  an unquoted path with spaces on the local computer (sdk#739).
- `WindowsSystemInformationClient.GetActiveConsoleUser()` returns the user signed
  in at the physical console (`WTSGetActiveConsoleSessionId`,
  `WTSQuerySessionInformationW`) as `ConsoleUser`, or null (sdk#739).
