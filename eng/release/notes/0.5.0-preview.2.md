# Runic SDK 0.5.0-preview.2

Runic Next Phase 2 adds a Runic Desktop host for generated Window/View clients
and puts the View SDK under the generic application package identities.

- `Runic.Application` replaces the Phase 1 `Runic.Application.Views` package.
  `Runic.Application.CsWebUi` now includes the scoped window factory, and
  `Runic.Application.Desktop` hosts Views through Runic Desktop.
- `Runic.Application.ReactiveUI` remains optional for applications using
  ReactiveUI ViewModels and routing.
- Svelte's View outlet is exported from `@runic-artifex/svelte/views`.
  Angular's outlet uses `@runic-artifex/angular`.
- The Translations Editor Window and root ViewModel use ReactiveUI. Its
  existing JSON operation facade remains while document workflows move to
  typed ViewModels in later slices.

The Phase 1 preview package IDs were not published. Projects using an earlier
source checkout should update package references and Svelte or Angular imports
to the IDs above. C# View namespaces remain unchanged in this preview.
