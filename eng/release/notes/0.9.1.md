# Runic SDK 0.9.1

Install matching `0.9.1` packages from NuGet and npm;
`Runic.Application.Views.CsWebUi` is `0.9.1-preview.1`. Command Line versions
remain independent of this SDK.

This patch release fixes security advisories in the frontend dependencies that
the project template generates. It changes no Runic API. Projects created from
the 0.9.0 template should apply the same updates to their own `package.json` and
lockfile ([#475](https://github.com/Runic-Artifex/runic-sdk/pull/475)).

## Security

- Vite 8.3.0 to 8.3.2 bundle `launch-editor` 2.14.1 or earlier, whose existence
  check can be bypassed on Windows
  ([GHSA-587h-7wmj-h5pm](https://github.com/advisories/GHSA-587h-7wmj-h5pm),
  high). The React, Vue and Svelte starters now pin Vite 8.3.4.
- The Angular starter moves from Angular 22.2.1 to 22.2.3. `@angular/cli` 22.2.3
  depends on `@modelcontextprotocol/server` 2.3.1, which fixes
  [GHSA-jm63-cq47-j5jp](https://github.com/advisories/GHSA-jm63-cq47-j5jp) and
  [GHSA-46jr-4wx8-v453](https://github.com/advisories/GHSA-46jr-4wx8-v453) (high)
  and [GHSA-rvq5-wwqv-78pq](https://github.com/advisories/GHSA-rvq5-wwqv-78pq).
- `@angular/build` 22.2.3 still requires Vite 8.3.0 exactly, so the Angular
  starter overrides Vite to 8.3.4: through `overrides` in `package.json` for npm
  and Bun, and through `pnpm-workspace.yaml`, which the template adds when pnpm
  is selected. Angular projects therefore install a second copy of rolldown. The
  override will be removed once a stable `@angular/build` accepts a fixed Vite.

## Dependency ranges

The npm packages' peer ranges are unchanged: `@runic-artifex/vite-plugin-runic`
accepts Vite `>=8.0.12 <9` and `@runic-artifex/angular` Angular `>=22.0.0 <23`,
so applications choose the patched versions themselves.
