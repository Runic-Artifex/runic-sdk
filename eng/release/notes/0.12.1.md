# Runic SDK 0.12.1

Install matching `0.12.1` packages from NuGet and npm;
`Runic.Application.Views.CsWebUi` is `0.12.1-preview.1`. Command Line versions
remain independent of this SDK.

This patch release rebuilds the SDK with the October 2026 security releases of
.NET, Node and Bun ([#659](https://github.com/Runic-Artifex/runic-sdk/pull/659)).
It changes no Runic API.

## Security

- [CVE-2026-111497](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-111497)
  is an out-of-bounds write in the Brotli decoder that .NET, Node and Bun bundle.
  Runic does not decode Brotli. An application is exposed if it decodes
  untrusted Brotli data itself: through `HttpClient` automatic decompression,
  ASP.NET Core request decompression or the `System.IO.Compression` Brotli APIs
  in .NET, or through the Node or Bun runtime in its frontend tooling.
- The packages are built with .NET SDK 10.0.403 (runtime 10.0.14). This also
  includes the October 13 .NET security release (10.0.13) and the re-released
  fixes for CVE-2026-70197 and CVE-2026-102870.
- The Microsoft packages that Runic packages depend on now require 10.0.14:
  - `Microsoft.Extensions.DependencyInjection.Abstractions` and
    `Microsoft.Extensions.Logging.Abstractions`;
  - `System.DirectoryServices.Protocols` for `Runic.Platform.Administration.Windows`.

  The project template references `Microsoft.Extensions.DependencyInjection`
  10.0.14.
- The template's default Bun is 1.4.4.

## Nix

- `buildRunicApplication` puts OpenSSL on the library path of self-contained
  and NativeAOT applications. Built with nixpkgs' binary .NET SDK (for example
  `dotnetCorePackages.sdk_10_0-bin`), such an application aborted at start with
  "No usable version of libssl was found"; with nixpkgs' source-built SDK
  nothing changes.

## What to update

- Install .NET SDK 10.0.403 or later (runtime 10.0.14) on development and build
  machines. Self-contained and NativeAOT packages embed the runtime they were
  built with, so republish them, including those from `dotnet runic package`.
- Update the Node and Bun used for frontends: Node 24.22.1 or 26.12.1, and Bun
  1.4.4 or later. Under Nix, `mkDevShell` uses your own nixpkgs' versions;
  update nixpkgs once it carries them.
- Raise the Runic package versions in your project to `0.12.1`.
