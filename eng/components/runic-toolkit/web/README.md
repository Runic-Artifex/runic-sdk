# Runic Toolkit web packages

`@runic-artifex/application-bridge` is the framework-neutral TypeScript runtime for a typed Runic Toolkit frontend.

```bash
npm install @runic-artifex/application-bridge
```

It requires Node.js 24.18 or later, TypeScript, and Effect. Use its controller directly with React, Vue, or Angular; use the Runic Svelte integration for SvelteKit applications. See the [package README](https://www.npmjs.com/package/@runic-artifex/application-bridge), [frontend guide](https://github.com/Runic-Artifex/runic-toolkit/blob/main/docs/guides/frontend-contracts.md), [examples](https://github.com/Runic-Artifex/runic-toolkit-examples), and [issues](https://github.com/Runic-Artifex/runic-toolkit/issues).
